## Adding New Audio

1. Add MP3 files to this directory
2. Update `themes/theme-config.js` to reference the new file
3. Document license info below

## File Requirements

- **Format**: MP3 (smaller file sizes, universal support)
- **Bitrate**: 128-192 kbps recommended
- **Duration**: 1-5 minutes (tracks loop automatically)
- **Style**: Ambient, chill, no heavy rhythms
